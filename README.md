# Calculator-Web-Application
A simple web-based calculator built using Python Flask, HTML, CSS, and Jinja2. Developed as a learning project by following PW Skills lectures by Md. Imran Sir, with additional debugging and troubleshooting support from ChatGPT.

Features
Addition
Subtraction
Multiplication
Division
Logarithmic Calculation
Dynamic Result Display
User-Friendly Interface
Flask-Based Backend Processing
Technologies Used
Python
Flask
HTML5
CSS3
Jinja2 Templates
